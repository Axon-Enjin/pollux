## How to print

1. Open the HTML in a browser. For the run-of-show, open the markdown and print from the viewer or paste into a one-page sheet.
2. File → Print. Margins: default. Background graphics: on.
3. Do not scale to fit if type becomes tiny. One page per HTML page.

## Do not print

- Guild sigil or UNESCO badge as publisher.
- The legacy lesson / game concept frame.
- Real hotlines, routes, or a second government QR from the kit URL.
